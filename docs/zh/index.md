# 世界模拟引擎

世界模拟引擎是一个实验性项目，用多智能体架构驱动角色扮演会话。它不追求成熟或高效，而是一次实验性的尝试，想弄清楚一个问题：用多智能体架构来模拟一个世界及其中的会话，究竟能做到什么程度？

## 功能

本软件使用复杂的多智能体架构，以及基于图数据库的结构化状态，尝试维持模拟会话的一致性和连续性。一些重要功能包括：

- **多智能体架构**：每个智能体负责模拟流程中的不同步骤，并拥有受限的知识和信息范围。这可以减少信息泄漏和事实漂移，也允许更复杂、更真实的模拟。每个智能体都可以单独配置，包括提供商、模型、提示词和其他参数。
- **结构化状态**：软件将模拟的结构化状态写入图数据库，而不是只保存叙事文本。这让状态管理更复杂也更真实。状态模拟和前端渲染相互解耦，因此同一状态可以用不同方式呈现。
- **基于时间和视角的模拟**：模拟由时间驱动，每个角色会基于之前事件和世界状态获得自己的视角。这让模拟更真实、更沉浸：角色会依据自己的视角拥有不同的知识和理解，即使用户没有与他们互动，也能靠内部触发机制继续行动。
- **一等媒体生成支持**：软件一等支持媒体生成，包括图像、视频（WIP）和音频。这可以带来更沉浸、更有表现力的模拟体验。
- **本地优先设计**：与一些主要依赖云端旗舰模型能力的系统不同，本软件尽量适配效果尚可的本地模型，以获得更高的隐私性和安全性。

请参考文档中的相应章节，了解每项功能的更多细节以及使用方式。
